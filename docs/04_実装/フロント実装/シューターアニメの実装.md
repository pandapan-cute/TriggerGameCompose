### 💻 enable3dで再現する実装ロジック

Three.js / enable3d の基本機能（`BoxGeometry` や `Tweens` 機能）を組み合わせることで作成できます。

#### 1. 小キューブ群（弾源）の生成

まずは 3×3×3 などの配置で小キューブを生成し、グループ（`THREE.Group`）にまとめます。

```javascript
// 弾の群れをまとめるグループ
const cubeGroup = new THREE.Group();
const cubes = [];

const size = 0.2; // 小キューブのサイズ
const gap = 0.05; // 隙間

for (let x = -1; x <= 1; x++) {
  for (let y = -1; y <= 1; y++) {
    for (let z = -1; z <= 1; z++) {
      // 発光マテリアルを適用したキューブを作成
      const geometry = new THREE.BoxGeometry(size, size, size);
      const material = new THREE.MeshStandardMaterial({
        color: 0x00ffff,
        emissive: 0x00ffff, // 発光色
        emissiveIntensity: 2.0
      });
      const cube = new THREE.Mesh(geometry, material);
      
      // 初期位置を設定
      cube.position.set(x * (size + gap), y * (size + gap), z * (size + gap));
      
      cubeGroup.add(cube);
      cubes.push(cube);
    }
  }
}

// キャラの手元や前方に配置
cubeGroup.position.set(player.position.x, player.position.y + 1.5, player.position.z + 1);
this.third.add.existing(cubeGroup);

```

#### 2. アニメーション（演出の3ステップ）

Phaser標準の **Tween（トゥイーン）** や enable3d のアニメーション機能を使って、アニメーションの「緩急」をつけます。

* **Step 1：出現（スケールイン）**
`cubeGroup.scale` を `0` から `1` に拡大させます。
* **Step 2：分割・タメ（拡散）**
各小キューブの `position` を一瞬外側に広げ、プレイヤーの構えに合わせて少し後ろに引きます（予備動作）。
* **Step 3：発射（連射または一斉射出）**
`this.tweens` などを使って、目標地点（敵の座標）へキューブを順番に飛ばします。

```javascript
// 連射アニメーションの例 (Phaser Tween)
cubes.forEach((cube, index) => {
  // 時間差（delay）をつけて1発ずつ敵へ飛ばす
  this.tweens.add({
    targets: cube.position,
    x: targetEnemy.position.x - cubeGroup.position.x,
    y: targetEnemy.position.y - cubeGroup.position.y,
    z: targetEnemy.position.z - cubeGroup.position.z,
    duration: 300, // 飛んでいくスピード
    delay: index * 50, // 50msごとに順次発射
    ease: 'Power2.easeIn', // 徐々に加速するイージング
    onComplete: () => {
      // 敵に着弾した時の処理（ダメージ計算・エフェクト生成・キューブの削除など）
      cube.destroy();
    }
  });
});

```

### 🌟 enable3dならではのメリットと表現力のアップ

1. **物理エンジン（Cannon.js）との連動が容易**
enable3dには物理エンジンが組み込まれているため、飛ばしたキューブに `this.third.physics.add.existing(cube)` で物理ボディを付与すれば、**「的に当たったらキューブが弾け飛ぶ・跳ね返る」** といったリアルな物理挙動が数行で書けます。
2. **サイバー感の演出（LineSegments）**
キューブのメッシュに `THREE.EdgesGeometry`（以前紹介したワイヤーフレーム枠線）を重ねると、エッジだけが明るく光るサイバー感あふれるキューブ弾になります。
3. **完全な動的制御**
「スキルレベルが上がったらキューブの数が 3×3 から 4×4 に増える」「敵の位置を自動追尾（ホーミング）する」といった演出も、コード側ですぐに拡張可能です。

Blenderではキャラ本体の「手をかざす・構えるポーズ（アニメーション）」だけを作成・エクスポートしておき、**「キューブの出現・分割・発射」の全エフェクトはenable3dのコード側で制御する**のが最も効率的でおすすめの構成です！
