# Mixamoアニメーションの軽量化＆Draco圧縮（GLB変換）

Mixamoからダウンロードした重いFBXデータを、キーフレーム間引きとDraco圧縮を駆使して極限まで軽量化（10MB ➔ 1.1MBなど）し、Phaser等のWeb環境へ最適化する全手順の完全版ドキュメントです。

---

## ダウンロード後の軽量化＆GLB変換手順

### 🛠️ 1. Blenderでのキーフレーム間引き（アニメーションのクリーンアップ）

MixamoのFBXは全フレームにデータが入っているため、まずは不要なコマを間引きます。

1. **ファイルをインポートする**

   * **ファイル ＞ インポート ＞ FBX (.fbx)** から、Mixamoでダウンロードしたアニメーション付きファイルを読み込む。

2. **骨（アーマチュア）を選択する**

   * オブジェクトモードで、キャラクターの「骨」をクリックして選択状態（オレンジ枠）にする。
   * *※骨を選択していないと、画面下にアニメーションデータが表示されません。*

3. **画面下を「ドープシート」に切り替える**

   * 画面下部（タイムライン等が表示されているエリア）の一番左上にある「時計マーク（または2つのひし形マーク）」のアイコンをクリックする。
   * エディタータイプの一覧から、アニメーション列にある **「ドープシート (Dope Sheet)」** を選択する。
   * 左上が「Object Mode」になっている場合は「Pose Mode」に切り替える。
   * *※これでヘッダーメニューに「キー (Key)」が表示されます。*

4. **キーフレームを全選択してクリーンアップする**

   * ドープシートのエリア（黄色いくの字マークが並んでいる場所）にマウスカーソルを移動する。
   * **`A` キー** を押して、すべてのキーフレームを全選択（明るいオレンジ色に変化）する。
   * メニューバーの **「キー (Key)」 ＞ 「Clean Keyframes」** を選択する。
   * *(ショートカット: 領域内で **`F3`** または **`Space`** を押し、`clean` と検索して実行でもOK)*

   * 画面左下のポップアップで感度（Threshold）を必要に応じて調整する（デフォルトの `0.05` でも十分間引かれます）。

---

### 📤 2. Blenderから「gLTF 2.0 (.glb)」形式でエクスポート

Webでの標準規格であり、テクスチャやアニメーションを1つに内包できる「GLB」へ変換します。

1. **ファイル ＞ エクスポート ＞ gLTF 2.0 (.glb)** を選択する。
2. 画面右側の設定パネルを以下の通りに調整する。

* **フォーマット (Format):** `gLTFバイナリ (.glb)`
* **Include ＞ 制限 (Limit to):** 必要に応じて `選択されたオブジェクト` にチェック。
* **トランスフォーム (Transform):** `Yが上方` にチェックが入っているか確認。
* **アニメーション (Animation) ＞ アニメーション (Animation):** **必ずチェックを入れる（オン）**。
* *※Mixamoのアニメーションを含めるため、今回はオンにします。*

1. 右下の **「gLTF 2.0をエクスポート」** をクリックして保存する。

---

### 📉 3. gltf.report でのDraco圧縮（極限のWeb最適化）

GoogleのDraco圧縮アルゴリズムを用いて、メッシュデータを数分の一に圧縮します。

1. ブラウザで [gltf.report](https://gltf.report/) にアクセスする。
2. 先ほどBlenderからエクスポートした `.glb` ファイルを画面にドラッグ＆ドロップする。
3. 画面右側に表示されるメニューの **「Export」** セクションを以下のように設定する。

* **format:** `Binary (.glb)`
* **buffers:** `Interleaved` （GPUが最も効率よく処理できる配列パターン）
* **compression:** **`Draco`** に変更する。
* **Draco compression ＞ method:** `Edgebreaker`
* **Draco compression ＞ quantize:** `Mesh`

1. 一番下にある **「Export」** ボタンをクリックしてダウンロードする。

## 🛠️ 4. Phaser（フロントエンド）側での受け入れ設定

Draco圧縮されたGLBモデルをPhaser（Three.jsなどの3Dライブラリを使用）で読み込む場合、ブラウザ側に解凍用のスクリプト（デコーダー）を読み込ませるコードが**必ず1行必要**になります。

### 💡 JavaScript / TypeScript 実装コード例

```javascript
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';
import { DRACOLoader } from 'three/examples/jsm/loaders/DRACOLoader.js';

// 1. 各種ローダーの初期化
const gltfLoader = new GLTFLoader();
const dracoLoader = new DRACOLoader();

// 2. Dracoデコーダーのパスを指定（超重要）
// ※使用しているライブラリの公式フォルダ内にある「draco」フォルダを、
// 自分のプロジェクトのパブリックなassetsディレクトリ等に配置して参照させます。
dracoLoader.setDecoderPath('/assets/draco/'); 

// 3. GLTFLoaderにDracoデコーダーをセット
gltfLoader.setDRACOLoader(dracoLoader);

// 4. 最適化済みGLBモデルのロード
gltfLoader.load(
    '/assets/models/idle.glb',
    (gltf) => {
        // ロード成功時の処理（シーンへの追加やアニメーション再生の開始）
        const model = gltf.scene;
        scene.add(model);
        
        // ミキサーのセットアップをしてMixamoアニメーションを再生
        const mixer = new THREE.AnimationMixer(model);
        const action = mixer.clipAction(gltf.animations[0]);
        action.play();
    },
    (xhr) => {
        console.log((xhr.loaded / xhr.total * 100) + '% loaded');
    },
    (error) => {
        console.error('エラーが発生しました:', error);
    }
);

```

## 📌 ワークフローのまとめ（カンペ用）

> **Mixamo (FBX)** ➔ **Blender (Dope Sheetでキー全選択 ➔ F3からClean Keyframes)** ➔ **BlenderからGLB出力 (Animationオン)** ➔ **gltf.report (Draco / Interleaved)** ➔ **Phaser (DRACOLoaderをセットしてロード)**

このドキュメント一式をNotionや開発メモ等にストックしておけば、次回以降の新キャラ実装時もスムーズに極小軽量データを作ることができます！
