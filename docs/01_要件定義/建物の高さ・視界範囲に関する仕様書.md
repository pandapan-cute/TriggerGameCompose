# 建物の高さ・視界範囲に関する仕様書

## 仕様の詳細

* 各セルに建物の高さを設定する
* 建物の高さは0~5とする
* 高さが1上がるごとに視界の範囲が1増える
* ユニットが移動時に現在より高いセルに移動する場合、高さの段数差によって追加で行動力を消費する
* 低いセルや同じ高さのセルに移動するときは移動分のみの行動力を消費する（1）
* 各キャラクターには共通の視界範囲を定義する
* 視界範囲外の敵ユニットは？で表示する
* 視界範囲外のバッグワームを装備している敵ユニットは非表示にする
* 視界範囲内の敵ユニットはキャラクターの画像を表示する
* 視界範囲内のバッグワームを装備している敵ユニットの場合もキャラクターの画像を表示する
