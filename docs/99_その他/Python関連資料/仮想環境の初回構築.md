# Python仮想環境の初回構築

## Python仮想環境の作成

```bash
# Python仮想環境の作成
python3 -m venv .venv

# Pythonの仮想環境に入る
source .venv/bin/activate

# Pythonの仮想環境に入った状態で、必要なライブラリをインストールする
pip install maturin stable-baselines3 tensorboard

# 仮想環境のライブラリリストを書き出す
pip freeze > requirements.txt

# Pythonの仮想環境から出る
deactivate
```

これで、requirements.txt というテキストファイルが生成され、そこに stable-baselines3 などの名前とバージョンが綺麗に書き出される。
この requirements.txt をGitの管理に含めます。
