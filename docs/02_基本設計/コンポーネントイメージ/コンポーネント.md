# コンポーネントについて

## 前提

コンポーネントイメージの都度修正は大変なので、
**最新のイメージはstorybookで確認**することを推奨します。

storybookの使い方はgame-clientのREADMEを参照してください。

コンポーネントイメージは実装前のイメージ共有のための資料であることをご了承ください。

## 対戦結果表示

- 対戦終了後の対戦結果を表示するコンポーネントとして用意

## ターン情報表示UI

ターンの移り変わりや現状をユーザーにしめすUI群の定義

### モード切替スライド

動きの設定やユニットの行動のモード切替を行うUIコンポーネントとして作成

- 「動きの設定」か「ユニットの行動」どちらに変わるのかの表示
  - ゲーム開始時にも表示させる
- 現在のターン数の表示
- 左から右にスライドしてフェードイン、少し待機してから右にスライドしてフェードアウトするアニメーション

### ターン状況表示カード

下記の情報を表示できるUIコンポーネントとして作成
ゲーム画面の右上に置くのが良いか

- 動きの設定の150秒
- ユニットの行動15秒
- 現在「動きの設定」か「ユニットの行動」なのかの表示
- 現在のターン数と最終ターン数
