# スプリント振り返り準備

## やること

1. スプリントレビューの準備
   - 今回のスプリントで達成した成果物をマークダウンで記載する
   - プレイ動画を撮影する

2. レトロスペクティブの準備
   - チームメンバーからのフィードバックを収集する
   - 改善点や成功点をリストアップする
   - 次のスプリントに向けたアクションアイテムを考える

3. スプリントプランニングの準備
   - バックログアイテムの優先順位を確認する
   - チームのキャパシティを見積もる
   - タスクの割り当てを考える

## 動画撮影反省点

- 章タイトルのアイキャッチは用意しておいたほうが良い
- アイキャッチもOBS studioのシーンにしておいて、章タイトルが変わるタイミングで切り替えると良さそう
- 今回はkdenliveとCapCutで編集したが、kdenliveだけで完結させたほうが効率が良さそう

- OBS studioで動画撮影する際のポイント
  - 動画撮影中はハキハキしゃべる。余計な発言いらないかも。
  - 章タイトルのアイキャッチを用意しておく
    -> 章タイトルは文字だけ変えるでもいい。文字変えてる間沈黙して、後で調整するのもあり。
- kdenliveで動画編集する際のポイント
  - 沈黙部分をカットする
  - BGMの追加
  - キャプションの追加

とはいえあまり時間をかけるのも。。

- 動画撮影：30分
- 動画編集：1時間
- アップロードやサムネイル作成など：30分

くらいが理想か。。

あと、**ちゃんとしたマイクが必要**
