# スプリント動画

## スプリント動画編集

### 1. auto-editorを使用して無音部分をカットする

```bash
auto-editor your_video.mp4 --margin 0.3sec
```

### 2. 音声認識機能（Speech to Text）を活用して字幕を自動生成する

[公式ドキュメント](https://docs.kdenlive.org/en/effects_and_filters/speech_to_text.html)

* 仮想環境のPythonを使ってもらいたいので、以下のコマンドを使ってKdenliveを開く

    ```bash
    PATH="$HOME/kdenlive_env/bin:$PATH" kdenlive
    ```

* 音声認識のモデルはLargeを選択する。多少時間はかかるけど。
