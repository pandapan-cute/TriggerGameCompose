# フォント追加方法（Next.js + Storybook）

本ドキュメントは、`Michroma` フォントを実際にプロジェクトへ追加した手順をまとめたものです。

## 目的

- Next.js本体画面でカスタムフォントを使えるようにする
- Storybookでも同じフォント表示を再現する

## 1. `next/font/google` でフォントを読み込む

対象ファイル: `game-client/app/layout.tsx`

```tsx
import { Geist, Geist_Mono, Michroma } from "next/font/google";

const geistSans = Geist({
 variable: "--font-geist-sans",
 subsets: ["latin"],
});

const geistMono = Geist_Mono({
 variable: "--font-geist-mono",
 subsets: ["latin"],
});

const michroma = Michroma({
 variable: "--font-michroma",
 subsets: ["latin"],
 weight: "400",
});
```

ポイント:

- `variable` を指定すると、CSS変数として扱える
- `body` の `className` に `michroma.variable` を含める

```tsx
<body className={`${geistSans.variable} ${geistMono.variable} ${michroma.variable} antialiased`}>
 {children}
</body>
```

## 2. CSS側で変数を使う

対象ファイル: `game-client/app/globals.css`

`@theme inline` と実際のクラスを定義する。

```css
@theme inline {
 --font-sans: var(--font-geist-sans);
 --font-mono: var(--font-geist-mono);
 --font-michroma: var(--font-michroma);
}

.font-michroma {
 font-family: var(--font-michroma), Helvetica, sans-serif;
}
```

使い方（コンポーネント側）:

```tsx
<span className="font-michroma">Bailout</span>
```

## 3. Storybookでも同じフォントを反映する

対象ファイル: `game-client/.storybook/preview.ts`

Storybookは `app/layout.tsx` を通らないため、
`layout.tsx` で付与している `--font-michroma` 変数が未定義になりやすい。

そのため、`preview.ts` でも同じフォント変数を付与する。

```ts
import "../app/globals.css";
import { Geist, Geist_Mono, Michroma } from "next/font/google";
import { createElement } from "react";

const geistSans = Geist({ variable: "--font-geist-sans", subsets: ["latin"] });
const geistMono = Geist_Mono({ variable: "--font-geist-mono", subsets: ["latin"] });
const michroma = Michroma({ variable: "--font-michroma", subsets: ["latin"], weight: "400" });

decorators: [
 (Story) =>
  createElement(
   "div",
   { className: `${geistSans.variable} ${geistMono.variable} ${michroma.variable} antialiased` },
   createElement(Story)
  ),
],
```

注意:

- `preview.ts` は `.ts` ファイルなので JSX ではなく `createElement` を使う
- `globals.css` の import も必要

## 4. 動作確認

```bash
cd game-client
npm run lint -- .storybook/preview.ts app/layout.tsx
npm run storybook -- --smoke-test
```

## よくあるハマりどころ

### Next.jsでは反映されるがStorybookでは反映されない

- 原因: Storybookは `layout.tsx` を通らない
- 対応: `preview.ts` で同じフォントvariableを付与する

### `font-michroma` クラスを書いたのに変わらない

- 原因: `globals.css` 側で `.font-michroma` 未定義
- 対応: `font-family: var(--font-michroma)` を定義する
