# スプリント動画

## スプリント振り返り・目標設定作成

### 1. スプリント振り返り・目標設定のマークダウンを作成する

1. `_振り返り・目標設定テンプレート.md`をコピーして、スプリントの振り返り・目標設定を記入する
2. `assets`フォルダ内に画像を置くフォルダを作る (例：202607_08)
3. 参照する画像を用意してフォルダに入れる

### 2. Marpでスライドに変換する

1. マークダウンファイルを開く
2. 右上のMarpアイコンをクリック
3. Export Slide Deckをクリック

### その他：pdfファイルの各ページを画像として出力する

```bash
# outpputフォルダを作っておく
pdftoppm -png -r 150 202607_08.pdf outputs/image
```

## スプリント動画編集

kdenliveは過去の動画をコピペして動画リソースだけ変更するのが早いと思われる。

### 1. auto-editorを使用して無音部分をカットする

```bash
auto-editor your_video.mp4 --margin 0.3sec
```

### 2. 音声認識機能（Speech to Text）を活用して字幕を自動生成する

[公式ドキュメント](https://docs.kdenlive.org/en/effects_and_filters/speech_to_text.html)

* 仮想環境のPythonを使ってもらいたいので、以下のコマンドを使ってKdenliveを開く

    ```bash
    PATH="$HOME/kdenlive_env/bin:$PATH" kdenlive
    ```

* 音声認識のモデルはLargeを選択する。多少時間はかかるけど。
