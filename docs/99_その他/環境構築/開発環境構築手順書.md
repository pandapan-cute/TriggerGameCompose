# 開発環境構築手順書

## 必要な開発ツールのインストール

### Docker / Docker Compose

docker composeで動作できるので、基本的にはDockerとDocker Composeさえあればローカルの実行環境が構築できます。

[Dockerの公式サイト](https://docs.docker.com/get-docker/)の手順でDockerをインストールしてください。
[Docker Composeの公式サイト](https://docs.docker.com/compose/install/)の手順でDocker Composeをインストールしてください。

それぞれのサブプロジェクトを開発するためには以下のインストールが必要です。

### Rust

[Rustの公式サイト](https://rust-lang.org/ja/learn/get-started/)の手順でRustをインストールしてください。

### Go

[Goの公式サイト](https://go.dev/doc/install)の手順でGoをインストールしてください。

### Next.js

[Next.jsの公式サイト](https://nextjs.org/docs/app/getting-started/installation)の手順でNext.jsをインストールしてください。
(そもそもNode.jsが必要なので、Node.jsもインストールしてください。)

## ライブラリのインストール

各サブプロジェクトのルートディレクトリで以下のコマンドを実行して、必要なライブラリをインストールしてください。

- game-client

```bash
cd game-client
npm install
```

- game_server

```bash
cd game_server/rust_app
cargo fetch
```

- local-websocket-apigateway

```bash
cd local-websocket-apigateway
go mod download
go mod tidy
```
